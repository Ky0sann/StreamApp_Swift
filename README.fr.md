## Description

StreamApp est une application de streaming moderne développée avec SwiftUI. Elle offre une expérience fluide et intuitive permettant de parcourir un catalogue de films, gérer ses favoris, noter les contenus et personnaliser son profil grâce à une interface native et performante.

## Utilisation

- Ouvrir le projet avec **Xcode**.
- Compiler et lancer l'application sur un simulateur iOS ou un appareil physique.

## API

**TMDB (The Movie Database)**  
https://developer.themoviedb.org/docs/getting-started

## Fonctionnalités

- Authentification (inscription, connexion, déconnexion)
- Gestion du profil utilisateur (consultation et modification)
- Récupération et affichage des films via l'API TMDB
- Détails d'un film (affiche, description, note)
- Gestion des favoris par utilisateur
- Notation et commentaires
- Nettoyage du cache

## Structure du projet

- Architecture MVVM
