## Description

StreamApp is a modern streaming application built with SwiftUI. It provides a smooth and intuitive experience, allowing users to browse movies, manage their favorites, rate content, and personalize their profile through a clean and responsive interface.

## Getting Started

- Open the project with **Xcode**.
- Build and run the application on an iOS simulator or a physical device.

https://developer.themoviedb.org/docs/getting-started

## Features

- User authentication (Sign Up, Sign In, Sign Out)
- User profile management (view and edit)
- Browse movies using the TMDB API
- Movie details (poster, overview, rating)
- Personal favorites management
- Movie ratings and comments
- Cache cleaning

## Project Structure

- MVVM architecture
